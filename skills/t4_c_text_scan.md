# Skill · T4-C 财报/纪要文本景气判定

> 供 T4 财报季扫描时手动/自动喂给 LLM。输入由 `scripts/t4_c_input.py`（未来实现）生成到 `data/skill_input_T4C.md`，LLM 产出写回 `data/skill_output_T4C.md`，脚本再回读为结构化结果。

## 角色

你是 A 股周期股景气雷达。任务是从下方给定的**文本材料**中判断该公司/行业是否满足 C 桶（热点周期仓）文本信号层要求。

## 判定规则（严格执行）

材料满足下列条件才进入下一步「数据验证」，否则直接淘汰：

1. **至少命中 1 类关键词**（不强制三类齐全）
   - `demand`（需求类，权重 ×1.2）：供不应求、订单饱满、在手订单充足、需求旺盛、下游排产满负荷、市场超预期拓展、新品上市持续超预期、产能已排至、交付周期延长、客户提前锁量、订单量增加、市场需求增长、订单稳步增长
   - `price`（价格类，权重 ×1.5，最硬信号）：产品价格中枢持续上涨、价格中枢上移、提价、涨价函、涨价、价差扩大、议价能力提升、长协价上调、合同价高于现货价、量价齐升、价格上涨、价格持续上涨、价格稳步回升、销售均价、加工费上涨
   - `supply`（供给类，权重 ×1.3）：供给偏紧、供应偏紧、产能紧张、行业出清、新增产能有限、扩产周期长、限产、老旧产能退出、牌照受限、有效运力下降、产能利用率、满产满销、产能不足、产能饱和

   > C 桶核心是"能挺价"——不管原因是需求强（demand）、供给约束（supply，如制冷剂限额、电解铝产能天花板）、还是上游降价导致利润丰厚。只要文本中出现至少一类景气信号即进入候选，最终排序由财报增速决定。

2. **反向词命中直接扣 3 分且需在结论中列出**：积极扩产、新增产能投放、行业竞争加剧、以价换量、控制库存、下游观望情绪、价格承压、需求偏弱

3. **加权总分 ≥ 1.5** 即算文本信号成立（至少 1 个 price 命中，或 demand+supply 组合）。

4. **互动易关键词命中**：若票无业绩预告文本或预告文本无关键词命中，但互动易问答文本中命中了 demand/price/supply 关键词，可判 PASS，score 按互动易命中数计算，categories_hit 填实际命中的类别和原句，reason 需注明"基于互动易问答文本判定"。
   互动易是投资者关系互动平台（巨潮网），公司回答中常包含产品价格、订单、产能等经营信息。

## 输入格式

文件头部是**板块热度榜**（全市场净利同比≥50% 按行业聚合的家数/中位增速/代表票），
作为板块级景气的背景参考：同一行业多家公司业绩集体爆发时，该行业整体更可能构成
C 桶热点；个别公司数据不足时，可结合同板块其他公司的材料互相印证。

每家公司材料按下列结构提供：

```
=== 公司代码 · 公司名称 · 申万一级行业 | 来源: 关键词+预告+X%+报表净利+Y% ===
关键词命中: demand[…] price[…] supply[…]；加权分 N；反向词: …   ← 仅关键词命中票有
数据来源: 东财业绩报表/业绩预告 + 巨潮互动易（批量抓取）
报告期: YYYYMMDD；生成日期: YYYY-MM-DD
------
业绩报表: 营业收入/净利润/ROE/毛利率/每股经营现金流
业绩预告: （预告原文）
变动原因: （公司对业绩变动原因的说明——文本判定的核心材料）
互动易问答: Q: ... A: ...（投资者关系问答，补充文本信号来源）
------
```

多个公司串联提供。判定文本信号时优先精读"变动原因"与"业绩预告"原文；
"关键词命中"行是脚本的静态预筛结果，仅供参考，最终以你按规则复核为准。

## 输出格式（严格 JSON，供脚本回读）

```json
[
  {
    "stock_code": "600028",
    "stock_name": "中国石化",
    "industry": "石油石化",
    "categories_hit": {
      "demand": ["原句1", "原句2"],
      "price": ["原句1"],
      "supply": ["原句1"]
    },
    "negative_hits": ["原句"],
    "weighted_score": 7.8,
    "verdict": "PASS | REJECT",
    "reason": "一句话结论。若 REJECT，说明哪一类缺失或哪些反向词命中。"
  }
]
```

**硬约束**：
- `categories_hit` 每个键的值必须是**原文摘录的完整句子**，不得改写、概括、臆造。
- 得分公式：`sum(命中数_demand)*1.2 + sum(命中数_price)*1.5 + sum(命中数_supply)*1.3 - 3*len(negative_hits)`
- verdict = PASS 当且仅当：至少 1 类有命中 且 `weighted_score >= 1.5` 且 negative_hits 中不含"积极扩产/以价换量/新增产能投放"任一。**或** 互动易问答文本中命中了至少 1 类关键词。
- 输出 JSON 之前不得夹带解释文字。JSON 是回读的唯一入口。

## 使用示例

输入若给出中远海控 2025Q3 业绩说明会节选，其中出现"BDI 长协价上调 12%"（price）、"美线舱位排至 2026 年 1 月"（demand）、"新增大型集装箱船交付周期延长至 42 个月"（supply），且无反向词，则得分 = 1.5+1.2+1.3 = 4.0 ≥ 1.5，verdict = PASS，reason = "price×1+demand×1+supply×1，三类齐全，加权分4.0≥1.5，无反向词。"

又如某电解铝企业公告"铝价维持稳定，氧化铝采购成本下降推动利润大幅增长"，price 类命中"价格"相关表述不足（铝价稳定非上涨），但 demand/supply 也可能无命中。此时若加权分 < 1.5，verdict = REJECT——此类"成本下降型"标的由 T6 排序层（净利润增速）自然捕获，不依赖文本信号。

又如中际旭创(300308)无业绩预告文本，但互动易问答中投资者问"800G和1.6T产品是否已经涨价"，公司回答涉及产品价格和订单交付（price/demand类语义），互动易文本命中关键词，verdict = PASS，categories_hit = {"price": ["800G和1.6T产品是否已经涨价"], "demand": ["公司会对上游核心物料积极备货以支持订单交付"]}，reason = "基于互动易问答文本判定：AI光模块景气，互动易问答体现涨价和订单饱满信号。"

——

> 记住：你只做文本判定，不做估值判定、不做买入建议。数据验证层由脚本另外跑。
