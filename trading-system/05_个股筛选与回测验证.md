# 三桶策略 · 个股筛选框架与回测验证

> 配套 `01_策略系统总纲.md` 与 `02_strategy_config.yaml`。
> 本文件解决两件事：① 三桶具体买哪只股票（落地筛选）；② 原框架里的经验阈值（如"股息率≥70%分位"）用历史数据校准，给出真实胜率。

> ⚠️ 本文档中的阈值为**待回测校准值**，回测结果见文末「第三章 回测与校准」，结论以真实数据为准。

## 第一章 红利桶（A 桶）个股筛选

### 1.1 候选行业池
高股息≠随便买。只从**分红文化稳定、现金流可预测**的行业取：
- 国有大行 / 股份行、煤炭（动力煤龙头）、电信运营商、电力（水电/核电）、高速公路、石化（炼化）、部分公用事业。
- **剔除**：分红忽高忽低的周期化工、地产链、靠一次性卖资产分红的公司。

### 1.2 第一步：分红可持续性过滤（最重要，过滤"假红利"）
高股息里一半是陷阱——股价跌得多显得股息率高，但公司快不行了。逐条过滤：

| 过滤项 | 规则 | 理由 |
|---|---|---|
| 连续分红 | 近 **5 年**现金分红不中断 | 中断一次即踢出，证明分红意愿不稳 |
| 分红支付率 | **30%–70%** | <30% 不愿分；>70% 不可持续，景气一差就砍 |
| 自由现金流覆盖 | FCF / 年度分红总额 ≥ **1.2** | 分红必须有真金白银，不是借钱分 |
| 盈利趋势 | 近 3 年净利润复合增速 ≥ **0%**（不连续两年下滑） | 利润塌了股息率再高也是镜花水月 |
| 负债约束 | 非金融资产负债率 < **60%**；银行看资本充足率达标 | 高杠杆下分红随时会被监管叫停 |
| 价值陷阱排除 | 剔除 PB<0.5 且 ROE<5% | 便宜到这个程度通常是基本面出了大问题 |

### 1.3 第二步：在合格池里按"性价比"排序买入
满足 1.2 后才进入排序。综合分 = 股息率(TTM) × 质量系数，质量系数由资产质量决定：

- **股息率(TTM)**：最近 12 个月每股分红 ÷ 当前股价，降序。
- **质量系数**（0.7–1.3）：ROE 稳定性、分红连续性年限、FCF 覆盖倍数加权。
- 最终按"综合分"降序，取前 N 只（N 由仓位 / 单票 ≤8% 决定）。

### 1.4 银行股专项：在银行里选哪一只
银行是红利桶主力，但 42 只银行股分化极大。用三维打分（每项 0–100，加权汇总）：

| 维度 | 指标 | 权重 | 选优方向 |
|---|---|---|---|
| 分红 | 股息率(TTM)、分红支付率 30–70%、连续分红年限 | 40% | 股息率高且支付率健康 |
| 资产质量 | 不良率（低好）、拨备覆盖率（高好，>250% 加分）、资本充足率 | 35% | 不良低、拨备厚 |
| 估值与息差 | PB 历史分位（低好）、净息差 NIM（不大幅恶化） | 25% | 低估值 + 息差企稳 |

- **国有大行**（工/建/农/中/交/邮储）：股息率最高、资产质量最稳，但弹性小、牛市长得慢 → 红利桶核心仓。
- **股份行**（招行/兴业/平安）：股息率波动大、周期性强 → 只在分位极低时配，不当核心。
- **城商行/农商行**：区域风险集中，原则上不进红利桶（除非是江浙优质行且分位极端低）。
- **实操建议**：红利桶银行部分用"国有大行打底 + 1 只低分位股份行增强"，不押单只。

## 第二章 成长桶（B 桶）与热门桶（C 桶）筛选

### 2.1 成长桶（B 桶）个股筛选
成长 = 业绩成长 × 行业前景，且估值要有性价比。

| 维度 | 规则 |
|---|---|
| 行业渗透率 | **5%–40%**（<5% 是风投，>40% 进价格战杀估值） |
| 业绩增速 | 近 4 季度营收/净利润复合增速 ≥ **25%**；最新单季不减速（环比 ≥0） |
| 利润质量 | 经营现金流 / 净利润 ≥ **0.7**（过滤纸面利润）；ROE ≥ **12%** 且向上 |
| 估值性价比 | **PEG ≤ 1.0**（或 ≤1.2 放宽）；PS 处行业历史分位 < 70% |
| 排雷 | 商誉/净资产 < 30%；前五大客户收入占比 < 50%；近 6 月高管减持 < 流通盘 1% |

排序：综合分 = 增速分 × 质量分 ÷ 估值分，取前若干只，单票 ≤6%。

### 2.2 热门桶（C 桶）个股筛选（落地版）
从你给的"财报/交流/调研 7 句话"出发，做成可机器执行的两关：

**第一关 · 关键词 + 反向词（结构化加权，来自 `02_strategy_config.yaml`）**
- 需求类 ×1.2 / 价格类 ×1.5 / 供给类 ×1.3，三类都命中且加权 ≥6 才进下一关。
- 反向词（"积极扩产""以价换量""库存高企"等）每条 −3 分，命中即淘汰。

**第二关 · 数据验证 ≥2 条（缺一不可，防止"嘴上景气"）**
从"业绩大增公司"出发筛：单季扣非净利同比 >50% **且** 环比加速，再叠加以下任 2 条：
- 行业运价/价格指数创年内新高；
- 单季毛利率环比 +2pct；
- 合同负债（预收款）同比 +30%；
- 经营现金流同比转正或大幅改善；
- 机构近 3 月上调盈利预测家数 ≥ 5。

**行业层确认**：所属申万一级行业指数近 3 月跑赢沪深 300，且行业处于上行周期（非顶部，见总纲"周期顶部反指"）。
命中后单票 ≤4%，同一行业 90 天内禁入重复触发。

## 第三章 参数回测验证框架

### 3.0 铁律：yaml 里的每个数字都必须有回测证据

原方案里的所有阈值——分位 70/80/90、股息率 5%、CAGR 20%、渗透率 5–40%、止损 -15%/-25%、
熔断 -15%/-20% 等——**都是待回测校准的经验值**，不是最终结论。

**硬规则：**
1. `02_strategy_config.yaml` 中任何数值型阈值的**首次设定或后续修改**，必须在本章节留下：
   触发信号定义 → 回测样本区间 → 胜率 / 收益 / 最大回撤 / 触发频率 → 参数敏感性 → 决策结论。
2. 未附回测证据的阈值调整一律视为**违反纪律**，写入季度归因复盘的规则违反计数。
3. 参数改动生效后进入**样本外观察期**（至少 2 个季度），期间原参数与新参数**并行影子跑**，
   两条曲线的分歧要能解释，否则回滚。
4. **不追求单点最优**，追求参数**稳健性**——胜率对阈值 ±10% 波动应保持相对稳定，
   出现"甜蜜点"陡峰（附近略微移动胜率就崩）视为过拟合，禁止采用。

### 3.2 回测方法学

**样本区间（至少覆盖以下四段行情，任一段表现极差就是策略未通过）**
- 2015.06–2016.02：股灾三连
- 2018 全年：熊市 + 贸易战
- 2020.03：疫情单日熔断
- 2021.02–2022.04：核心资产泡沫 → 破裂
- 2022.10–2024.01：磨底 + 二次探底
- 2024.09：地量反弹
- 若数据可得，加 2007–2008 与 2011 两段极端。

**标的池**
- A 桶：中证红利指数成分股（历史成分动态调整，用 point-in-time 快照，禁止用当前成分回溯）
- B 桶：申万一级行业中划定成长属性行业（TMT/医药/新能源/高端制造）当期市值前 200
- C 桶：全 A 剔除金融地产，动态取"最近一期单季扣非同比 >50%" 的股票池

**信号定义原则（防未来函数）**
1. 所有指标必须用 T-1 日及之前的数据计算，禁止用 T 日收盘价参与 T 日买入
2. 财报数据用**披露日**而非报告期，避免 4 月 30 日的年报被 3 月的信号提前使用
3. 分位数用**滚动历史窗口**，禁止用整段样本做归一化
4. 一致预期数据用**信号触发日当时**的值，禁止用后修正版
5. **计价口径**：回测与 signal_log 事后回补均以"触发日 T+1 开盘价"起算，"T+1+N 开盘价"终止，
   全部用**前复权**价格，分红自动再投入。T+1 停牌用复牌首日开盘价；停牌 >20 交易日的信号作废

**业绩基准分桶化（重要）**

不同桶用不同基准。跑赢沪深 300 在红利风格年是遍地都是的现象，只有跑赢**桶基准**才叫真 alpha：

| 桶 | 基准代码 | 名称 | 理由 |
|---|---|---|---|
| A | 000922.SH | 中证红利 | 剔除风格 beta，只留红利里的选股能力 |
| B | 399006.SZ 或 931643.SH | 创业板指 / 双创50 | 剔除成长风格 beta，二选一在 yaml 里配置 |
| C | 该股所属申万一级行业指数 | 动态 | 周期股 alpha = 跑赢自己行业，不是跑赢全市场 |
| 组合 | 四桶基准加权 | 按当前 allocation.states 权重 | 跟策略仓位表联动 |

**回测和 signal_log 必须同时输出三种超额**：
- 绝对收益（原始）
- 对沪深 300 超额（跨风格对比用）
- 对分桶基准超额（**判定参数是否失效的主门槛**）

T7 决策矩阵里的"胜率"从此以后指的是**对分桶基准的超额胜率**，不再是对沪深 300。

**评估指标（每条参数至少输出这 6 个）**

| 指标 | 定义 | 阈值 |
|---|---|---|
| 胜率 | 触发信号后 60/120/250 日**对分桶基准**正超额比例 | ≥ 55% 合格，≥ 60% 优秀 |
| 中位数超额 | 触发后各持有期**对分桶基准**的中位数超额收益 | 应显著为正 |
| 最大回撤 | 触发后持有期内的最大回撤（绝对） | 越小越好 |
| 收益/回撤比 | 中位数超额 / 最大回撤 | ≥ 1.5 合格 |
| 触发频率 | 年化触发次数 | 与预期节奏匹配（如 A 桶 S2 全历史 ≤ 3–4 次/年） |
| 参数敏感性 | 阈值 ±10% 时胜率变化 | 变化 ≤ 5pct 视为稳健 |

**分组验证（防过拟合）**
- 样本内（in-sample）：前 60% 时间用于选参数
- 样本外（out-of-sample）：后 40% 时间用于验证
- 样本外胜率 < 样本内胜率 -10pct → 判定为过拟合，参数不采用
- 有余力时做 **walk-forward** 滚动：每 2 年重训一次，观察参数是否漂移

**数据源三条腿（缺一不可）**

回测的可信度来自三个独立数据源交叉验证，任一条腿单独用都不够：

| 腿 | 数据来源 | 覆盖时间 | 作用 |
|---|---|---|---|
| 历史回测 | akshare/tushare 历史行情+财报 | 2015 至上季度末 | 找参数、验稳健性 |
| 样本外验证 | 上述数据的后 40% 时段 | 与历史回测同源但分组隔离 | 防过拟合 |
| **实盘 signal_log** | `07_信号台账.csv`，由 T8 维护 | 策略上线后每一条真实触发的信号 | 判断参数在**当下市场**是否还灵 |

**实盘 signal_log 是最重要的一条腿**——历史回测永远是"过去的答案"，signal_log 是"当下的证据"。
判定规则：
- 实盘胜率 ≥ 回测预期 -5pct → 参数正常
- 实盘胜率 < 回测预期 -10pct 且样本 ≥ 5 条 → **参数失效预警**，不等定期回测就要触发 T7
- 触发频率显著偏离回测预期 → 阈值可能过松或过严
- 样本 < 5 条 → 数据不足，只记录不下结论

**T7 分桶节奏**（对应 `03_Agent定期任务.md` T7 头部说明）：
- A 桶 / B 桶：季度末跑一次
- **C 桶：月度跑一次**（周期股参数漂移快，季度节奏会滞后半个周期）
- yaml 修改前：临时触发，只跑目标参数

### 3.3 参数调整决策矩阵

回测跑完后，每个参数按以下矩阵决策：

| 样本内胜率 | 样本外胜率 | 敏感性 | 决策 |
|---|---|---|---|
| ≥ 60% | ≥ 55% | 稳健 | **采用**，写入 yaml |
| ≥ 55% | ≥ 50% | 稳健 | **保留现值**，进入观察期 |
| ≥ 55% | 但样本外下降 >10pct | — | **判定过拟合**，回退到更保守的邻近值 |
| 任一区间 | — | 敏感性差（陡峰） | **拒绝**，改用更稳的阈值 |
| < 50% | — | — | **信号本身无效**，考虑淘汰该指标 |

### 3.4 已完成的回测结果（可追加）

**A 桶 · 股息率分位阈值扫描**（截至最新一次 `06_backtest_dividend.py` 运行）

参考 `06_backtest_dividend_result.csv`。当前观察：
- 分位 90 / 250 日：胜率 54.06%，均值收益 5.83% —— 边际合格
- 分位 80 / 250 日：胜率 52.99%，均值收益 6.24%
- 分位 70 / 120 日：胜率 43.10%，均值收益 1.97% —— **不达标**，中位数为负
- 60 分位在所有持有期胜率都在 50% 附近，几乎无信号价值

**初步结论**：
1. 高分位（≥80）+ 长持有期（≥250 日）胜率较稳，与 A 桶"逆向+长持"性格吻合
2. 70 分位 120 日样本表现异常差，可能存在拥挤反噬，需交叉验证
3. 短持有期（60 日）在所有分位下都无优势，说明 A 桶不适合做波段
