# Agent 定期任务包

> 每个任务块可**直接复制**成一条定时任务的 prompt。
> 统一前置：读取 `02_strategy_config.yaml` 作为唯一阈值来源；读取 `05_持仓与日志.csv` 获取当前持仓。
> 统一输出：按 `alerts.message_template` 格式；无触发时输出「本次无信号」+ 指标快照，不要编造。

## T1 · 每日盘后风控扫描（交易日 16:00）

```
角色：三桶策略系统的风控执行器。
数据源：优先用自选股/行情 MCP，缺失则用 akshare。

请依次完成：
1. 读取 trading-system/02_strategy_config.yaml 与 05_持仓与日志.csv。
2. C 桶监控：
   - 取每个 C 桶持仓对应的产品/运价指数（见 config.data_sources.shipping_indices 及标的映射），
     计算最新值、60日均线、距1年高点回撤%。
   - 判定规则 C-E1 / C-E2 / C-T3 是否触发。
3. 全组合止损检查：
   - B 桶：现价 vs 持仓均价，跌破 -25% → B 止损
   - C 桶：跌破 -15% → C 止损
   - C 桶浮盈 ≥40% / ≥80% → 分批止盈提示（C-E4 / C-E5）
4. 集中度检查：
   - 单票占总资产 >8%（A桶）/ >6%（B桶）/ >4%（C桶）
   - 单申万一级行业合计 >20%
5. 组合回撤：自净值高点回撤是否达 -15% / -20% 熔断线。

输出：
- 先给一句话结论（有无 P0/P1）
- 触发项按 P0 → P1 → P2 排序，每条含：规则ID、标的、当前值、阈值、建议动作、建议股数
- 附一张当日指标快照表（C桶指数、组合净值、回撤、各桶权重）
无触发时明确写「本日无触发，系统正常」。
```

## T2 · 每周红利状态判定（周一 08:30）

```
角色：三桶策略系统的 A 桶（红利逆向仓）择时判定器。

请依次完成：
1. 取以下数据（截至上周五收盘）：
   a. 中证红利指数 000922 的股息率，及其近5年历史分位
   b. 10年期国债到期收益率 → 计算 ERP = 红利股息率 − 10Y国债
   c. 中证红利 vs Wind全A 近60个交易日相对超额收益%
   d. 全市场当日成交额中，成交额前3大申万一级行业的占比%
   e. 沪深300 上周最大单日跌幅、近20日最大回撤
2. 按 config.bucket_A.market_signals 逐条对照 S1/S2/S3 阈值，
   统计每一档达标条件数（need >= 2）。
3. 判定当前状态档位（取最高达标档），与上周状态对比。
4. 若发生状态跃迁（如 S0→S1、S1→S2）：
   - 查 allocation.states 给出新的四桶目标权重
   - 计算相对当前实际权重需要买入/卖出的金额
   - 检查该档位是否在 90 天冷却期内（same_tier_cooldown_days），若在则只提示不建议下单
5. B 桶顺带更新：各持仓 PE(TTM) 上市以来分位、PEG，标出触发 B-E4 的标的。

输出：
- 【状态判定】当前 Sx，上周 Sx，是否跃迁
- 【指标明细表】5 项指标的 当前值 / S1阈值 / S2阈值 / S3阈值 / 是否达标
- 【调仓建议】若跃迁，给出四桶目标权重与具体买卖金额；A 桶按 ladder 分档投入
- 【候选池筛查】用 bucket_A.stock_filters 全部硬门槛，从中证红利成分股中筛出合格标的，
  按「股息率 × PB分位倒数」排序输出前 15 只，并标注是否命中 value_trap_veto
```

## T3 · 月度再平衡检查（每月首个交易日）

```
角色：三桶策略系统的仓位管理器。

1. 计算 A/B/C/D 四桶当前实际权重。
2. 对照当前状态档位的目标权重，算出偏离（pct）。
3. 任一桶偏离 >5pct → 生成再平衡建议（含具体标的与金额），
   遵守：D桶不低于15%；D桶资金不得直接进C桶；卖出优先卖已触发减仓规则的标的。
4. 汇总本月：分红到账金额、C 桶已兑现利润 → 按 profit_withdrawal 规则计算应转入 D 桶的金额。
5. 统计本月规则违反次数（对照 portfolio_risk.prohibitions 与交易日志）。

输出：四桶权重对比表 + 再平衡指令清单 + 本月纪律记分卡。
```

## T4 · 财报季扫描（4月 / 8月 / 10月，每周一次）

```
角色：三桶策略系统的基本面复核器 + C 桶景气雷达。

【任务A：B 桶质量全量复核】
对每只 B 桶持仓，用最新财报重算 quality_filters 全部 8 项指标，
逐项标 PASS / FAIL，并判定是否触发 B-E1/B-E2/B-E3。
特别关注：扣非增速、经营现金流/净利润、应收增速 vs 营收增速。

【任务B：C 桶文本信号扫描】
1. 目标范围：最近一期单季扣非同比 >50% 的公司（可先用财务筛选缩小到 100 只内）。
2. 抓取其：最新财报「管理层讨论与分析」、业绩说明会记录、近3个月机构调研纪要。
3. 按 bucket_C.text_signal 的三类词库计分：
   - demand ×1.2, price ×1.5, supply ×1.3，negative 每条 -3
   - 要求三类均有命中 且 加权总分 ≥6
4. 对文本信号成立的标的，做 data_validation 交叉验证（需 ≥2 条成立）。
5. 对通过双确认的标的，再跑 top_reversal_signals 四条反指；命中任一 → 直接淘汰。

输出：
- B 桶复核表（标的 × 8项指标 × PASS/FAIL × 建议动作）
- C 桶候选表：标的 / 加权得分 / 命中的具体原文摘录（必须附原句）/ 数据验证通过项 / 反指检查结果 / 结论(建议买入·观察·淘汰)
- 严格要求：每条关键词命中必须给出原文出处与句子，不得概括或臆造。

【任务C：A 桶分红政策核查】
核对每只 A 桶持仓最新分红预案：派息率、是否维持、是否有取消迹象。
命中 A-E3 → 标 P0。
```

## T5 · 季度归因复盘（季末）

```
角色：三桶策略系统的复盘分析师。

统计本季度：
1. 分桶业绩：A/B/C 各自收益率、对组合总收益的贡献度、最大回撤
2. 交易质量：各桶交易次数、胜率、平均盈亏比、平均持有天数
3. 信号质量：
   - A 桶状态跃迁次数（年化 >6 次说明阈值过松）
   - C 桶信号触发数 vs 实际盈利数（信号准确率）
   - 被止损标的中，事后 60 天是否继续下跌（验证止损有效性）
4. 纪律：违反 prohibitions 的次数与具体事件
5. 参数建议：仅提出 1 个最该调整的参数及理由，不得一次改多个

输出：一页复盘报告 + 一张「本季最该改进的 1 件事」结论。
```

## T6 · 三桶候选股池生成（按需触发 / 建议每月首个交易日与 T3 同跑）

> **标注约定**：任务内部对每一步用【脚本】/【判定】区分静态与动态部分，为后续拆分预留边界。
> - 【脚本】= 纯量化条件，仅依赖行情/财报结构化数据，未来应下沉为 Python 脚本，直接产出候选表 CSV
> - 【判定】= 需要 LLM 读财报正文、调研纪要、行业报告做语义级判断，保留在 skill 里执行
> 目的：脚本先把范围缩到几百只以内，LLM 只在最后一层做深度判定，尽量少烧 token。

```

数据源：优先 westock-mcp / akshare / tushare；财报正文与调研纪要走公司公告与券商研报库。
统一前置：读取 02_strategy_config.yaml 作为唯一阈值来源。

请依次完成三桶筛选：

━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【A 桶 · 红利】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【脚本】步骤 A-1  全市场硬门槛过滤（预期返回 ≤ 200 只）
按 bucket_A.stock_filters 全部条件筛：
  - 近12月股息率 ≥ 5.0%
  - 连续分红年数 ≥ 5
  - 派息率 ∈ [30%, 70%]
  - 近5年 ROE 均值 ≥ 8%
  - 近3年自由现金流均为正
  - 非金融有息负债率 < 60%
  - PB 近5年分位 ≤ 30%
  - 近3年营收未连续下滑
  - 近6月无大股东大额减持
任一项不满足直接剔除。

【脚本】步骤 A-2  综合评分排序
score_A = 股息率(TTM) × (1 − PB分位) × ROE_5y均值
取 score_A 前 30 只交给判定层。

【判定】步骤 A-3  价值陷阱三连否（LLM 读财报）
对 A-2 前 30 只，逐只阅读：最新年报「管理层讨论与分析」、所在行业协会公告、
最近 6 个月券商行业深度。判断是否命中 bucket_A.value_trap_veto 三条：
  ① 主业营收是否连续两年下滑
  ② 分红是否依赖资产处置或增加负债（看筹资/投资活动现金流与分红金额关系）
  ③ 所属行业是否产能永久性过剩
三条同时命中 → 剔除，必须附引用原句与出处（公告日期/研报名称/页码）。

【判定】步骤 A-4  行业集中度模拟
从 A-3 通过者中挑 10 只，模拟组合的申万一级行业分布，任一行业占比 ≤ 20%。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【B 桶 · 成长】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【脚本】步骤 B-1  质量硬门槛（预期返回 ≤ 300 只）
按 bucket_B.quality_filters 全部满足：
  - 近3年营收 CAGR ≥ 20%
  - 近3年扣非净利 CAGR ≥ 20%
  - 毛利率近3年波动 < 3pct
  - 经营现金流/净利润 近3年均值 ≥ 0.7
  - 应收账款增速 ≤ 营收增速 × 1.2
  - 商誉/净资产 < 20%

【脚本】步骤 B-2  估值满足任一
  - PEG（未来2年一致预期）≤ 1.0
  - PE(TTM) 上市以来分位 ≤ 40%
  - 高研发型（研发费用率 > 10%）PS 分位 ≤ 35%

【判定】步骤 B-3  行业渗透率判定（B 桶最关键的一步）

  - 渗透率 > 40% → 剔除（进入价格战）

【C 桶 · 周期】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  - 单季扣非环比为正

【判定】步骤 C-2  文本信号扫描（C 桶核心工作，token 消耗大头）
对 C-1 通过者，抓取：最新财报 MD&A、业绩说明会记录、近 3 个月机构调研纪要。
按 bucket_C.text_signal 三类词库计分：
  - demand ×1.2, price ×1.5, supply ×1.3
  - negative_keywords 每命中一条扣 3 分
要求三类均有命中 且 加权总分 ≥ 6。
每条命中必须附原句与出处（公告日期/文件名），不得概括或臆造。

（C 桶宁缺勿滥，未通过全流程的一律不进池）
```

## T7 · 参数回测验证（A/B 桶季度 · C 桶月度 · yaml 修改前强制执行）

> **纪律**：`02_strategy_config.yaml` 里任何数值阈值的调整都必须先过 T7，产出的证据追加到
> `05_个股筛选与回测验证.md` 第 3.5 节 changelog，才允许 commit。**未经回测的参数修改视为违反纪律。**
>
> **分桶节奏（重要）：**
> - **A 桶 / B 桶**：季度末执行一次（3/6/9/12 月末），Ⅰ/Ⅱ 类参数全量重算
>   理由：红利/成长信号本身低频（A 桶年触发 3–6 次，B 桶按财报季），季度节奏足够
> - **C 桶**：**每月执行一次**（月末），文本得分阈值、数据验证条件数、止损/止盈参数重算
>   理由：周期股景气切换快、参数漂移快，季度频率会滞后半个周期
> - **任何桶 · yaml 修改前**：临时触发，只跑待改参数
>
> **实盘反馈闭环（新增，与 T8 联动）：**
> 每次 T7 除了跑历史回测，还必须读取 `outputs/signal_log_YYYYMMDD.csv`（由 T8 维护），
> 把最近一个季度/一个月的**实盘信号事后表现**与回测预期做对比：
> - 实盘胜率 ≥ 回测预期 -5pct → 参数正常
> - 实盘胜率 < 回测预期 -10pct → **参数失效预警**，即使定期回测未到期也提前触发调参
> - 实盘触发频率显著高于/低于回测预期 → 阈值可能过松/过严
>

> - 【判定】= 结合宏观背景解读结果、决定采用/回退/拒绝，需要 LLM 参与
>
> **参数变更规则（pick 胜率最高，但要过双检验）：**
> 1. 网格扫描出胜率最高点后，必须验证：样本外胜率 ≥ 该点样本内胜率 −10pct
> 2. 敏感性：胜率最高点 ±10% 邻居的胜率不能陡跌（>5pct）
> 3. 两项都过 → 变更 yaml，同时启用 2 个季度（C 桶为 2 个月）的**新旧参数影子并跑**
> 4. 有任一不过 → 保留现值或回退到更保守邻居

## T8 · 信号台账维护（每日盘后 · 事后 60/120/250 日回补收益）

> **用途**：为 T7 提供"实盘反馈"数据源。历史回测跑的是过去的信号，signal_log 记的是**当前策略实际触发过的信号**，两者对齐后才能判断"参数在当下市场是否还灵"。

> - **全量记录**：T1–T4 触发的每条信号都必须写入 `07_信号台账.csv`（模板见 `07_信号台账模板.csv`），**不管是否实际下单**。未下单的信号是最重要的对照组。

> - **不可回改**：已经写入的字段禁止修改。参数变更是插入新信号，不是覆盖旧信号。

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

**计价口径（防未来函数，与 05 第 3.2 节一致）：**
  - 起算价 = 触发日 **T+1 开盘价**（不是 T 日收盘价，避免偷一天信息）
  - 终止价 = T+1+N 交易日**开盘价**（N=60/120/250）
  - 全部用**前复权**价格，分红自动再投入
  - 触发日 T+1 停牌 → 用复牌首日开盘价代替；停牌超过 20 交易日 → 该信号作废，

  - A 桶跑赢沪深 300 只是风格 beta（红利风格年遍地跑赢）
  - A 桶跑赢中证红利才叫真选股 alpha
  - B 桶跑赢创业板指才叫真选股 alpha

判定：
  - 实盘分桶基准超额胜率 < 回测预期 -10pct **且样本 ≥ 5** → 输出「参数失效预警」，建议提前触发 T7

  - 触发频率 < 回测预期 × 0.5 → 建议放宽阈值或复核数据源
  - 其他 → 正常，仅记录

【判定】环节要 LLM 说明可能的宏观原因（例如"当前处于极端流动性宽松周期，红利信号触发数
下降属于合理，不建议改阈值"），不要一看到偏离就急着建议调参。
```
