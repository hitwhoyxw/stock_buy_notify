# 三桶资产交易策略系统 v1.0

> 目标：把「红利逆向 / 成长 / 热点周期」三条思路，变成一套**可量化触发、可自动监控、可机械执行**的系统。
> 定位：主观框架 + 规则化纪律。不是全自动量化，是「Agent 盯盘报警 → 人做最终确认 → 按预设仓位表下单」。

---

## 一、先说你原思路的 8 个缺口（这是本次补的核心）

| # | 缺口 | 为什么致命 | 本文档的补法 |
|---|---|---|---|
| 1 | **只有买入，没有卖出** | 三桶里最赚钱的是卖点，尤其周期股 | 每桶独立的止盈/止损/逻辑证伪三套出场 |
| 2 | **"极端事件""性价比"没有量化定义** | 无法交给脚本，也无法事后复盘对错 | 全部转成分位数 / 利差 / 阈值 |
| 3 | **没有弹药管理** | 你的红利桶是事件驱动的，机会来了没钱＝策略归零 | 引入 D 桶（类固收弹药库）+ 四状态仓位表 |
| 4 | **没有集中度上限** | 红利桶极易变成"银行+煤炭+电力"三行业 80% | 单票 ≤8%、单申万一级行业 ≤20% |
| 5 | **周期股缺"反向证伪"** | 周期股顶部特征是**低 PE + 高利润**，你的关键词法在顶部信号最强 | 加入四条顶部反指（详见 C 桶） |
| 6 | **成长股缺行业生命周期定位** | 渗透率 >50% 后再买成长，必吃戴维斯双杀 | 渗透率 5%–40% 才纳入 |
| 7 | **没有组合级熔断** | 三桶同时错，回撤会失控 | 组合回撤 -15% / -20% 两级熔断 |
| 8 | **没有交易日志与归因** | 无法迭代，第二年还是同样的错 | 强制日志模板 + 季度归因 |

## 二、总体架构

```
总资产 100%
├── A 桶  红利逆向仓      逆向、集中、事件驱动、长持       波动低 · 提供现金流
├── B 桶  成长仓          分批、分散、基本面驱动           波动中 · 提供弹性
├── C 桶  热点周期仓      快进快出、硬止损、景气驱动       波动高 · 提供爆发力
└── D 桶  弹药库          货基/国债逆回购/短债/同业存单     波动极低 · A 桶的子弹
```

**核心机制：D 桶 → A 桶 单向输血。**
市场越恐慌、红利越便宜，D 桶的钱越多地流进 A 桶。这是整套系统的主发动机，也是你原思路「不定投、等极端事件重仓」的唯一实现方式。

## 三、仓位表（这是你要的具体比例）

### 3.1 四状态动态仓位（默认方案 · 平衡型）

状态由 **A 桶信号档位** 决定（见 §4.1），全组合跟着切换：

| 状态 | 触发条件 | A 红利 | B 成长 | C 热点 | D 弹药 |
|---|---|---:|---:|---:|---:|
| **S0 常态** | 无信号 | **20%** | 25% | 10% | **45%** |
| **S1 偏低估** | 红利股息率分位 ≥70% | **30%** | 25% | 10% | 35% |
| **S2 显著低估** | 分位 ≥80% 或 ERP ≥4.0% | **40%** | 27% | 8% | 25% |
| **S3 极端恐慌** | 分位 ≥90% 或 指数月跌>10% / 单日>3%+成交萎缩 | **55%** | 30% | **0%** | 15% |

> **S3 时 C 桶强制归零**：系统性恐慌中周期股跌得比谁都狠，这时候的钱必须让给 A 桶。这条是硬规则。

### 3.2 桶内细则

| 桶 | 单票上限（占总资产） | 持股数量 | 建仓方式 | 硬止损 |
|---|---|---|---|---|
| A 红利 | 8% | 5–8 只 | 三档金字塔（30/30/40） | 无（用逻辑止损） |
| B 成长 | 6% | 4–6 只 | 四批等额（25×4） | -25% |
| C 热点 | 4% | 2–4 只 | 两批（60/40） | **-15%** |
| D 弹药 | — | — | — | — |

**行业集中度：** 任一申万一级行业（含全部三桶合计）≤ 总资产 **20%**。红利桶最容易触线，硬约束。

### 3.3 风险偏好调节（按需替换默认方案）

| 方案 | S0 状态下 A/B/C/D | 适用 |
|---|---|---|
| 保守 | 20 / 15 / 5 / 60 | 资金是刚需钱、回撤容忍 <10% |
| **平衡（默认）** | **20 / 25 / 10 / 45** | 长期闲钱、回撤容忍 15–20% |
| 进取 | 25 / 32 / 15 / 28 | 长期闲钱、回撤容忍 >25%、有精力盯 C 桶 |

## 四、A 桶 · 红利逆向仓

### 4.1 买入信号（分档，全部可计算）

**第一层：市场级择时信号（决定档位与仓位状态）**

| 指标 | 数据 | 一档 S1 | 二档 S2 | 三档 S3 |
|---|---|---|---|---|
| 中证红利(000922)股息率 | 近5年分位 | ≥70% | ≥80% | ≥90% |
| 股息风险溢价 ERP = 红利股息率 − 10Y 国债 | pct | ≥3.0 | ≥4.0 | ≥5.0 |
| 红利指数 60日相对 Wind全A 超额 | pct | ≤ −5 | ≤ −8 | ≤ −12 |
| 拥挤度反向：全市场成交额前 3 热门行业占比 | pct | ≥35 | ≥42 | ≥48 |
| 事件：沪深300 单日跌幅 / 20日回撤 | — | −2% / −8% | −3% / −12% | −5% / −18% |

**判定：任意 2 项达标即入该档；跨档以最高达标档为准。**

对应动作：
- 触发 S1 → 投入 A 桶弹药的 **30%**
- 触发 S2 → 再投 **30%**
- 触发 S3 → 再投 **40%**（打满）

> 补充规则：**同一档位 90 天内只执行一次**，防止指标在阈值附近反复抖动导致过度交易。

**第二层：个股筛选（必须全部满足，硬门槛）**

| 项 | 阈值 | 剔除理由 |
|---|---|---|
| 近12月股息率 | ≥ 5.0% | — |
| 连续分红年数 | ≥ 5 年不中断 | 分红不稳定＝伪红利 |
| 派息率 | 30%–70% | >70% 不可持续，<30% 诚意不足 |
| 近5年 ROE 均值 | ≥ 8% | 净资产收益能力 |
| 自由现金流 FCF | 近3年均为正 | **关键：分红不能靠借钱** |
| 有息负债率（非金融） | < 60% | 同上 |
| PB | 历史 30% 分位以下 | 便宜 |
| 近3年营收 | 未连续下滑 | 排除衰退型价值陷阱 |
| 大股东/高管 | 近6月无大额减持、无质押爆仓风险 | — |

> **价值陷阱三连否**：主业连续两年下滑 + 分红靠变卖资产 + 行业产能永久性过剩 → 无论股息率多高，一票否决。

### 4.2 卖出规则

| 触发 | 动作 |
|---|---|
| 股息率回落至近5年 **30% 分位以下** | 减仓 50%，钱回 D 桶 |
| 股息率 < 10Y 国债 + 1.5pct | 清仓 |
| 派息率骤降 / 宣布取消分红 | **无条件清仓（当日）** |
| 扣非净利连续两年下滑 >15% | 清仓 |
| 单票占比因上涨超 10% | 减回 8% |
| 组合状态从 S3 回落到 S1 | 按新状态表被动减仓 |

**A 桶不设价格止损。** 逻辑没坏就是加仓机会，逻辑坏了当天走 —— 这是红利桶的性格。

## 五、B 桶 · 成长仓

### 5.1 三重筛选

**① 公司质量（全部满足）**
- 近3年营收 CAGR ≥ 20%，扣非净利 CAGR ≥ 20%
- 毛利率近3年稳定或上行（波动 <3pct）
- 经营现金流 / 净利润 近3年均值 ≥ 0.7 ← **过滤纸面利润**
- 研发费用率处于行业前 1/3（科技/制造类适用）
- 应收账款增速 ≤ 营收增速 × 1.2 ← **过滤靠赊销做大的收入**
- 商誉 / 净资产 < 20%

**② 行业前景（全部满足）**
- **行业渗透率处于 5%–40% 区间** ← 这是你原思路里缺的最关键一条
  - <5%：技术路线未定，是风投不是二级
  - >40%：进入价格战，龙头也要杀估值
- 未来3年行业空间 CAGR ≥ 15%（券商一致预期 / 第三方数据）
- 公司份额稳定或提升（不能是行业涨、自己被抢）
- 无颠覆性替代技术在 2 年内落地

**③ 估值性价比（满足任一）**
- PEG（用未来2年一致预期增速）≤ 1.0，理想 ≤ 0.8
- PE(TTM) 处于自身上市以来 <40% 分位
- 高研发型可用 PS 分位 <35% + 经营性现金流转正预期明确

### 5.2 分批建仓（4 批 × 25%）

| 批次 | 触发 |
|---|---|
| 第 1 批 | 三重筛选全部通过当日 |
| 第 2 批 | 较首批成本下跌 12%，**且**基本面无恶化（最近一期财报达标） |
| 第 3 批 | 再跌 12%，**且**基本面无恶化 |
| 第 4 批 | 再跌 12%（累计约 -33%），**且**基本面无恶化 |

**补充：时间轴备用触发** —— 若不下跌但持续满足估值条件，每满 1 个季度补 1 批，最多补到满仓。防止「等回调等到踏空」。

> **加仓熔断**：任一期财报增速 <15% 或不及一致预期 20% 以上 → **立即停止后续所有加仓**，转入卖出评估。绝不摊平已证伪的成长股。

### 5.3 卖出规则

| 触发 | 动作 |
|---|---|
| 连续 2 个季度扣非增速 < 15% | 清仓 |
| 单季不及一致预期 >20% 且管理层下调指引 | 清仓 |
| 经营现金流/净利润 跌破 0.5 | 减 50%，观察一期 |
| PEG > 1.8 或 PE 分位 > 85% | 减 50% |
| 行业渗透率 > 60% 且出现明显价格战 | 清仓 |
| 核心管理层/技术带头人离职 | 减 50% |
| **硬止损 -25%**（相对持仓均价） | 清仓，冷静期 60 天不得回补 |

## 六、C 桶 · 热点周期仓（你的关键词法 + 数据双确认）

> 周期股的钱是「景气度贴现」的钱，赚的是**斜率**不是**估值**。所以：进场看斜率，出场也看斜率，绝不看 PE。

### 6.1 文本信号层（你原方案的结构化版本）

从**财报 / 业绩说明会 / 调研纪要 / 招股书 / 行业协会通稿**中扫描，分三类计分：

**需求类（权重 ×1.2）**
`供不应求` `订单饱满` `在手订单充足` `需求旺盛` `下游排产满负荷` `市场超预期拓展` `新品上市持续超预期` `产能已排至 X 月`

**价格类（权重 ×1.5）** ← 最硬的信号
`产品价格中枢持续上涨` `提价` `涨价函` `价差扩大` `议价能力提升` `合同价高于现货价`

**供给类（权重 ×1.3）**
`供给偏紧` `产能紧张` `行业出清` `新增产能有限` `扩产周期长` `环保/政策限产` `老旧产能退出`

**计分：** 每命中一个独立表述计 1 分 × 权重。
- 三类**均有命中** 且 **加权总分 ≥ 6** → 文本信号成立
- 只命中需求类不成立（管理层最爱吹需求，最不敢吹价格）

**反向词库（命中即扣 3 分）**
`积极扩产` `新增产能投放` `行业竞争加剧` `以价换量` `控制库存` `下游观望情绪`

### 6.2 数据验证层（必须 ≥2 条成立，才允许下单）

| 验证项 | 阈值 | 示例数据源 |
|---|---|---|
| 产品/运价指数 | 近3月上行且创 1 年新高 | BDI、BDTI/VLCC-TCE、克拉克森新船价格指数、百川盈孚、Wind 商品 |
| 单季扣非同比 | > 50% 且环比 > 0（**加速**） | 财报 |
| 毛利率环比 | 提升 ≥ 2pct | 财报 |
| 合同负债 / 预收款同比 | > 30% | 财报 |
| 产能利用率 | > 90% | 财报/调研 |
| 行业月度数据 | 连续 3 月同比正增且加速 | 行业协会、海关、统计局 |

> **文本成立 + 数据 ≥2 条 = 买入信号。** 只有关键词，不买。

### 6.3 顶部反指（你原方案完全缺失，命中任一即清仓）

1. **PE(TTM) < 8x 同时单季利润创历史新高** → 典型周期顶，市场在提前贴现盈利下滑
2. **行业资本开支 / 新签扩产订单同比大增** → 供给端要来了，故事结束
3. **产品价格/运价指数跌破 60 日均线，或自高点回落 15%**
4. **卖方研报数量、机构调研次数同时创 1 年新高** → 拥挤度见顶

### 6.4 出场规则（C 桶纪律最严）

| 触发 | 动作 |
|---|---|
| 价格/运价指数跌破 60 日均线 | **减 50%（当日）** |
| 自高点回落 15%（指数或个股） | 清仓 |
| 命中任一顶部反指 | 清仓 |
| 浮盈 +40% | 减 50%，剩余启用移动止盈（回撤 10% 走） |
| 浮盈 +80% | 再减 50%（保留 25% 底仓吃趋势） |
| **硬止损 -15%** | 清仓，该行业 90 天内不得再进 |
| 持有满 6 个月景气未兑现（利润未加速） | 时间止损，清仓 |
| 组合进入 S3 状态 | 强制清零 |

**利润提现规则：** C 桶每次兑现的**利润的 50% 转入 D 桶**，永不复投回 C 桶。这条能保证你在周期赌对一次后，真正把钱留下来。

## 七、D 桶 · 弹药库

| 工具 | 占 D 桶 | 说明 |
|---|---|---|
| 国债逆回购 / 货币基金 | 40% | T+0/T+1，随时可用 |
| 短债基金 | 40% | 年化 2–3%，T+1 |
| 同业存单指数基金 | 20% | 年化 2% 左右 |

**规则：**
- D 桶只向 A 桶输血，**不得直接流向 C 桶**（防止追热点）
- D 桶占比任何时候 **不低于 15%**（S3 极端状态下的地板）
- 年度分红收入、C 桶提现利润，默认先进 D 桶

## 八、组合级风控（三桶之上）

| 层级 | 触发 | 动作 |
|---|---|---|
| 一级 | 组合自高点回撤 **-15%** | 暂停一切新开仓 7 天，做全量复盘，只允许执行卖出 |
| 二级 | 组合自高点回撤 **-20%** | C 桶强制清零；B 桶减半；A 桶按信号档位继续买（这是逆向仓的职责） |
| 集中度 | 单申万一级行业 > 20% | 5 个交易日内减回 |
| 单票 | 任一个股 > 8% | 减回上限 |
| 换手 | C 桶年换手 > 8 次 | 说明在追涨杀跌，强制暂停 C 桶一个季度 |

### 负面清单（绝对禁止）
- ❌ 任何形式的杠杆（融资、场外配资）买 B/C 桶
- ❌ C 桶亏损后加倍摊平
- ❌ 把 A 桶或 D 桶的钱临时挪去追 C 桶热点
- ❌ 无信号时"手痒"建仓
- ❌ 一次性 all-in 任何一只票
- ❌ 已止损的标的在冷静期内回补

## 十一、验证与迭代

**总纲铁律：`02_strategy_config.yaml` 里的每个数值阈值都必须有回测证据支撑，不接受"经验拍脑袋"值。**
详细方法学见 `05_个股筛选与回测验证.md` 第三章，执行任务见 `03_Agent定期任务.md` 的 T7。

上线前必须完成的三件事：

1. **参数首次校准**：对 yaml 里所有 Ⅰ/Ⅱ 类参数（择时信号阈值 + 个股筛选门槛）跑 T7 参数回测，
   任一参数样本外胜率 <50% 视为无效信号，需替换或淘汰。回测结果与决策依据落进 05 第 3.4 节。

2. **历史极端窗口压力测试**：三桶策略在以下窗口分别单独跑回测，任一窗口出现单桶胜率 <40%
   或组合回撤 >25% 都要重新审视参数：
   - 2015.06–2016.02（股灾三连）
   - 2018 全年（贸易战 + 熊市）
   - 2020.02–2020.04（疫情熔断）
   - 2021.02–2022.04（核心资产泡沫→破裂）
   - 2022.10–2024.01（磨底 + 二次探底）
   - 2024.09（地量反弹）

3. **纸面运行 ≥ 3 个月**：只记录信号不下单，统计信号频率与胜率。
   - A 桶年化状态跃迁 > 6 次 → 阈值过松，收紧
   - C 桶信号触发数 / 实际盈利数 < 50% → 文本或数据阈值过松，收紧
   - 任一桶 3 个月零信号 → 阈值过严，放宽

上线后的迭代纪律：

1. **动态调参节奏（按桶分频率）：**
   - A 桶 / B 桶：**季度末**跑 T7-AB，全量重算 Ⅰ/Ⅱ 类参数
   - C 桶：**月度末**跑 T7-C（周期股参数漂移快，季度会滞后半个周期）
   - 任何桶 yaml 修改前：临时触发 T7，只跑目标参数
2. **信号台账 signal_log 是动态调参的第三条腿：**
   `07_信号台账.csv` 由 T8 每日维护，记录 T1–T4 触发的**每一条**信号（无论是否下单），
   事后 60/120/250 日回补收益。这条腿的作用是让大模型能判断"参数在**当下市场**是否还灵"，
   而不是只看历史回测。
   - 实盘胜率 < 回测预期 -10pct 且样本 ≥ 5 → **参数失效预警**，不等定期回测就触发 T7
3. **任何 yaml 修改必须先过 T7**，且 T7 决策时必须读 T8 的实盘 signal_log 做对照，
   证据追加到 05 第 3.5 节 changelog，才允许 commit。未附证据的修改视为违反纪律。
4. **参数改动生效后进入影子并跑期**：A/B 桶 2 个季度、C 桶 2 个月。期间原参数与新参数并行输出信号，
   分歧点必须能给出解释；不能解释的分歧强制回滚。
5. **不追求单点最优**：胜率对阈值 ±10% 波动应稳定；出现"甜蜜点"陡峰视为过拟合，禁止采用。
6. **T5 季度归因复盘** 是提出参数修改建议的入口，T7 是验证入口，T8 是实盘反馈入口；三个环节缺一不可。

## 十二、部署与客户端（落地形态）

本节只做索引，详细方案见 `08_部署与客户端.md`。

- **云端执行**：所有 T1–T8 任务托管在 GitHub Actions，用私有仓库 + Secrets 管理数据源 token；`data/live_signal_log.csv` 与 `data/live_trade_log.csv` 是所有派生产物的唯一事实源。
- **推送通知**：P0/P1 走企业微信群机器人 + 飞书 webhook + 邮箱三通道，静默时段与幂等策略见 08 号文档。
- **客户端**：首版走 PWA（Cloudflare Workers / Vercel 后端 + D1/Turso 存储），提供仪表盘、持仓录入、交易录入、提醒中心、台账/回测/归因查阅五类页面。
- **闭环形态**：提醒卡片 → 客户端确认页 → 回写 04/07 CSV → GitHub commit → T8 消费执行状态并回补收益。
- **落地节奏**：先 T8 台账打通 → T1 每日闭环上云 → Notifier 三通道 → PWA 只读版 → 写路径 → 回测/归因页。
